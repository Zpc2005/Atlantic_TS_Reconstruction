# Release checklist

- [ ] Confirm author list, affiliations, repository URL and version.
- [ ] Confirm project-code ownership and final license.
- [ ] Verify third-party dependency notices.
- [ ] Verify PIRATA and WOA23 redistribution terms.
- [ ] Review security audit and remove private paths/secrets.
- [ ] Confirm large-file/checkpoint policy.
- [ ] Confirm derived-data public subset.
- [ ] Review unresolved figure visual-lineage statements.
- [ ] Pin final environment and dependency files.
- [ ] Finalize CITATION.cff.
- [ ] Create GitHub release and Zenodo deposit only after author approval.
