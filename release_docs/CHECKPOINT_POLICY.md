# Checkpoint release policy

Recommendation: **NOT_REQUIRED for the initial GitHub release; optional ZENODO archival only after author approval.**

The manuscript package contains frozen predictions, metrics and source records. Checkpoints are large binary artifacts with unresolved release/licensing and historical-environment questions. No checkpoint is included in this candidate. Releasing one later would require a completeness check, SHA-256 inventory, storage plan, license confirmation and a documented reason it is necessary for reproduction.
