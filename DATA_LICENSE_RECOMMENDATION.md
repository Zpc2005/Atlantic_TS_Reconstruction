# Data license recommendation

Project-generated derived scientific data remain:

`AUTHOR-GENERATED DERIVED DATA / FINAL DATA LICENSE TO BE DECIDED SEPARATELY`

No blanket data license is assigned in this release. PIRATA and WOA23 remain `REFERENCE_ONLY_DO_NOT_REDISTRIBUTE`; their official archives are not included. Derived scientific assets are included only where `RELEASE_CONTENTS.csv` marks them for release and remain subject to a separate final data-license decision.
