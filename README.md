# Atlantic_TS_Reconstruction v1.0.0

This repository contains the public reproducibility package for the tropical Atlantic PIRATA temperature and salinity reconstruction study.

It contains frozen derived data products, experiment definitions, selected research code, supplementary materials and provenance for the tropical Atlantic PIRATA temperature and salinity reconstruction study. M1 is random missing-observation reconstruction, M2 is continuous temporal-gap reconstruction and M3 is unseen-station spatial extrapolation.

PIRATA and WOA23 are referenced, not redistributed. Author-generated derived scientific assets are included only where `RELEASE_CONTENTS.csv` marks them for inclusion and remain subject to a separate final data-license decision. Project-owned/project-generated source code is licensed under BSD-3-Clause.

The package reproduces the documented scientific analyses and scientific figure values from frozen records. It does not claim that every historical final presentation refinement is pixel-perfectly reproducible.

The package does not claim one-command or pixel-perfect reproduction of every final manuscript figure. Visual lineage remains unresolved for Figures 3, 5, 7, 9 and S2, while scientific traceability remains documented.

Repository: https://github.com/Zpc2005/Atlantic_TS_Reconstruction
